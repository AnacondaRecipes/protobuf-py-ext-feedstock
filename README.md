Installing protobuf-py-ext
==================

Installing `protobuf-py-ext` from the main channel can be achieved by:

```
conda install protobuf-py-ext
```

It is possible to list all of the versions of `protobuf-py-ext` available on your platform with `conda`:

```
conda search protobuf-py-ext
```
